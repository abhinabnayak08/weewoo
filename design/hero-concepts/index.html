Where each one wins

01 Aurora — best if the goal is memorability. One number, huge, on air. Lowest information density, highest impact. Weakest at explaining how sharing works, so the section below it has to carry that.

02 The Ledger — best if the goal is conversion. It does the arithmetic for the visitor in the first screen, which is exactly the objection ("is it really cheaper?") that loses the sale. Recommended as the default.

03 Midnight — best if the goal is repositioning. Reads premium rather than discount, and it's already consistent with the login page, so nothing new is introduced to the brand.

All three run on the existing tokens — no colour was invented. Brand marks are flat colour stand-ins; drop in the real SVG logos before shipping.
